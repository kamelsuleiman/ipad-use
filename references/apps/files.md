# Files (com.apple.DocumentsApp)

| Landmark | Label (type) | Where |
|---|---|---|
| iCloud Drive | «iCloud Drive» (Cell) | sidebar → Locations |
| On My iPad | «On My iPad» (Cell) | sidebar |
| Recents / Shared | «Recents», «Shared» (Cell) | sidebar top |
| Item | «<name>, <size/count>» (Cell) | grid/list |
| Search | «Search» (Button) | top right |

## Fast paths
- **Open a folder/file**: `see --find "<name>"` then tap the **Cell's icon area**, not the name text.
- **Install a .shortcut / open a document from iCloud Drive**: navigate to it and tap the icon once; iCloud-only
  items download first (cloud badge), tap again to open.

## Gotchas
- Tapping the NAME of a selected item starts a **rename** (text gets selected). Tap the icon, or tap elsewhere to cancel.
- Delete / Move to Trash / Remove Download → the safety gate asks for approval.
